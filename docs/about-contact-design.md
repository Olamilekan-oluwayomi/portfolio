# About, Contact and Experience design revision

The owner requested a stronger design for About and Contact, describing the existing pages as lifeless. The implementation draws from the existing homepage typography and cobalt/lime palette (`src/app/page.tsx`, `src/styles/tokens.css`).

About pairs its existing "The Record" heading with a cobalt identity panel. Role, employer, location and stack still come from `siteIdentity`. Its chronological list retains the approved timeline, makes the intentional gap legible and highlights the latest recorded chapter. The existing decision-theme counts are displayed as static proportional bars, each based on its count divided by the total. Only owner-verified decisions belonging to published projects or the site enter those counts (`src/app/about/page.tsx`, `src/content/timeline.ts`, `src/content/identity.ts`, `src/content/release.ts`). No new biographical account, project metric or owner decision was authored.

Contact uses the existing "Let's talk" invitation, a cobalt email action, a lime availability panel and separate profile/CV links. Email, availability, location and link destinations come from the shared identity. The email stays in Instrument Serif, with a soft wrap opportunity before its domain. Clipboard success and failure feedback, the 1.5-second status window and the plain mailto link remain available. The clipboard writes the complete identity email rather than the wrapped display (`src/app/contact/page.tsx`, `src/components/copy-email.tsx`, `src/content/identity.ts`; `PRD.md` section 20).

The new layout is server-rendered with CSS. It reuses local fonts and existing tokens; there is no new dependency. Column layouts become one column at 767px, with an additional narrow layout at 359px. Controls retain explicit keyboard focus, accessible names and at least 44px target heights. The existing email underline is the only animated Contact feedback; the other new surfaces use static state changes (`src/styles/globals.css`, `src/components/copy-email.tsx`; `PRD.md` sections 25 and 28).

Viewport geometry, browser interaction and screen-reader behavior remain unverified until browser checks are available. Source-level responsive rules and HTTP checks do not establish those results. The implementation record is `docs/about-contact-design.json`, outside the published decision collection with `verified: false`. Release remains unchanged (`src/content/release.ts`).

Experience extends this composition with a typographic "The Log" heading, separate date, role and organization columns, and explicit View details/Close details controls. Its existing public entries and reverse chronological order are retained. Only entries with approved summaries expand through native details elements; PitchMatter remains company, role and dates only. Mobile rows place dates above the role and use a 44px expansion control with an accessible action label. No animation or client JavaScript is added (`src/app/experience/page.tsx`, `src/content/log.ts`, `src/styles/globals.css`; `PRD.md` section 18).
